# NYC Taxi Demand Forecasting

## Overview
Forecasted NYC taxi demand using Linear Regression 
with lag and time-based features.

## Results
- Achieved 28% lower MAE than Random Walk baseline
- MAE: 899 trips vs baseline 1,256 trips

## Methods
- Random Walk baseline
- Feature engineering (lag features, hour, day of week)
- Linear Regression
- Temporal train/test split

## Tools
Python, Pandas, Scikit-learn, Matplotlib
